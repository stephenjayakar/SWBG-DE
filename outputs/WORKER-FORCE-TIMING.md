# Worker portraits, Force combat and game time

The old builder portrait came from worker job records. Empire worker 83 used the converted Units icon 2, but builders 118/212 still used source icon 59. That index now belongs to an unrelated portrait. All 24 source worker records in each faction use frame 59 on their own faction's source sheet, so the adapter now copies the converted faction worker icon to all of them. No new artwork is needed.

Armed Jedi/Sith (source class 50) previously mapped to DE monk class 18. This gives enemy clicks conversion behavior. The adapter now maps them to infantry class 6, keeps source damage/reload/graphics, and uses native combat-task targeting. Source class effects and task selectors are translated with the new class mapping so their original membership is preserved. Holocron carriers remain separate class 43 and require testing.

Knights/Masters whose source conversion task is active receive DE's explicit non-monk conversion ability. Padawans do not receive it. The native Sun Ce unit (2040) supplies a known charge configuration: type -4, one charge, 15 game-second recharge and 38% conversion rolls. Source task minimum/maximum conversion times and the source nine-tile conversion range are retained. This is an MVP combat adapter, **not source-exact Force energy or conversion balance**. Source conversion upgrades, building/monk target restrictions, Force Meditation, carried Holocrons and conversion animations require further adaptation/testing. Select the **Force Conversion** ability before targeting an enemy to convert; ordinary enemy clicks are intended for melee combat.

Game speed scales simulation time. AI's 120-second timer means 120 **game seconds**, so it takes about 60 real seconds at 2x speed. Source movement speed, melee reload, train and research durations remain in the game's data; no extra wall-clock multiplier is applied by this repair. Custom nursery/repair scripts use `xsGetGameTime()`. Nursery income now multiplies its per-second rate by elapsed game seconds, matching aircraft repair's existing elapsed-time accounting. Paused time adds no income; a delayed callback catches up for continuously garrisoned animals. Membership changes between callbacks and save/load still require runtime verification.

Checks cover all 48 worker records, 805 serialized Force records (including editor/unused records), 585 conversion configurations, source melee reloads, explicit Empire and Rebel Padawan/Knight/Master cases, and time accounting across regular, skipped and paused callbacks. Gaia retains its source conversion-range resource of zero; the playable factions use nine. The checks do not execute DE. The user will run the game.
