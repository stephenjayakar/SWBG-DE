# SWGB in Age of Empires II: DE - installer

This experimental **0.0.2-dev** build plays the Star Wars Galactic Battlegrounds Galactic Empire and Rebel Alliance inside Age of Empires II: Definitive Edition. The download contains **no** Star Wars or DE game art, sound or music. The installer builds those from your own game installs.

The game is two mods:

- **SWBG-Logic**: the data mod (DAT, tech trees, UI tables, civ picker images). It is published as unlisted [mod 549437](https://www.ageofempires.com/mods/details/549437/) on ageofempires.com, and the installer carries an identical local copy.
- **SWBG-Data**: the graphics, sounds, music, icons, strings, maps and AI, generated by the installer from your SWGB files.

## What you need

- **Age of Empires II: Definitive Edition**. Steam is tested. Microsoft Store is detected but untested.
- **Star Wars Galactic Battlegrounds Saga**, from Steam or GOG.
- **Expanding Fronts 1.5.5**: the free fan expansion. Use the "Full" download. Merge its `GAME` folder into your SWGB `Game` folder; its *Manual Installation Guide* shows how. Then start `battlegrounds_x2.exe` **once**. Its "First Run" step converts the original art (`graphics_p1.drs` and similar files). The port uses EF's Empire/Rebel artwork, sounds and music.
- Windows 10 or 11, and about 4 GB of free disk space. Python, Java and other tools are not needed.
- For multiplayer: a subscription to [mod 549437](https://www.ageofempires.com/mods/details/549437/) (SWBG-Logic, version 1.7 for this installer). Subscribe, start DE once so it downloads, then quit before installing.

## Install

1. Close Age of Empires II: DE.
2. Run **SWGB-DE-Installer-0.0.2-dev-<build>.exe** and press **I** (Install). Or, with the ZIP, extract it anywhere and double-click **Install-SWGB-DE.cmd**. Both run the same installer. (**R** / `Repair-SWGB-DE.cmd` only re-enables SWBG-Data and fixes stale mod entries; see [My Mods, the lobby and Repair](#my-mods-the-lobby-and-repair).)
   - The exe is not code-signed, so Windows SmartScreen shows "Windows protected your PC". Click **More info > Run anyway**. Some antivirus tools may also flag unsigned exes; the ZIP with the `.cmd` is the alternative.
   - The exe is a small launcher with the ZIP's contents embedded. It checks their SHA-256, extracts them to `%TEMP%`, runs `installer\Install-SWGB-DE.ps1` in its window, deletes the temporary copy afterwards and returns the installer's exit code. `-ExtractTo <folder>` only extracts the files.
3. The installer finds DE, your DE profile and SWGB, checks that Expanding Fronts is present and refuses if DE is running. It then:
   - converts 2,414 sprites, 1,386 sounds, 38 music tracks and 352 interface icons from your SWGB/EF files;
   - rebuilds DE's 12 unit/tech/building/panel icon atlases with DE's own `texconv`;
   - installs **SWBG-Data** into `%USERPROFILE%\Games\Age of Empires 2 DE\<profile>\mods\local\`;
   - for **SWBG-Logic**: if you are subscribed to mod 549437 (a `mods\subscribed\549437_*` folder with the DAT) and its game files are identical to this release's SWBG-Logic, it uses that copy and installs no local one, removing a local SWBG-Logic that an earlier run installed. Otherwise, including when the subscription is an older version, it installs a local **SWBG-Logic**, which works in single player, and switches the subscription off;
   - enables SWBG-Data and the one Logic mod in DE's `mods\mod-status.json`. You never end up with two Logic mods enabled. Mod 549437's entry is found by its WorkshopID or `549437_` folder prefix. If DE has already written an entry for the current `549437_*` folder, the installer updates that entry and removes entries left over from an older folder name. Otherwise it points the old entry at the current folder;
   - warns if your copy of mod 549437 still has an older folder name (`549437_SWGB-DE-Factions-Publish`). DE will download the renamed listing on its next start and rename the folder (see below);
   - prints how to play, and a reminder that multiplayer needs the subscribed mod 549437.

   On a typical PC this takes about 1-2 minutes. Every generated file is checked against the reference build. The log and a per-file report are stored in `%LOCALAPPDATA%\SWGB-DE-Installer\logs`.

Options can be passed to the `.exe`, the `.cmd` or `installer\Install-SWGB-DE.ps1`. Run the exe with `-?` for a summary:

| Option | Meaning |
| --- | --- |
| `-SwgbPath "D:\Games\Star Wars - Galactic Battlegrounds"` | Your SWGB folder, if not found automatically |
| `-DePath "D:\SteamLibrary\steamapps\common\AoE2DE"` | Your DE folder, if not found automatically |
| `-ProfileId 7656119...` | DE profile to install into. You are asked if there are several |
| `-Repair` | Only fix `mod-status.json`: enable SWBG-Data again, point mod 549437's entry at its current folder and remove stale entries; nothing is regenerated. Needs an existing install. Same as **R** in the exe and `Repair-SWGB-DE.cmd` |
| `-NoEnable` | Leave `mod-status.json` alone. Enable SWBG-Data yourself in My Mods |
| `-Yes` | No prompts. Uses the most recently used profile |

Running the installer again is safe. It regenerates everything and replaces its own previous install. If SWBG mod folders already exist that the installer did **not** create, it moves them to `%LOCALAPPDATA%\SWGB-DE-Installer\backups\<time>\` first. It also backs up `mod-status.json` there before editing it.

### Upgrading from the older mod names

Earlier releases used the folder names **SWGB-DE-Factions-Draft** (data), **SWGB-DE-Factions-Assets** (media) and, for the publishing copy, **SWGB-DE-Factions-Publish**. On install, any of these in `mods\local` are moved to `%LOCALAPPDATA%\SWGB-DE-Installer\backups\<time>\` and their `mod-status.json` entries are removed. Nothing is deleted:

- Folders that an earlier version of this installer created are recorded as superseded. `-Uninstall` does not put them back; the backup copy can be deleted.
- Other copies (for example from the old full share ZIP, or a local publishing copy) are recorded as backups. `-Uninstall` restores them together with their `mod-status.json` entries.

### My Mods, the lobby and Repair

SWBG-Logic is a *data mod*. DE writes `"Enabled": false` for every data mod, local or subscribed, in `mod-status.json` each time it starts, so **Mods > My Mods** always shows SWBG-Logic as disabled. That is normal: DE still lists data mods in the lobby's **Data Mod** dropdown, and that is where SWBG-Logic is chosen. SWBG-Data is an ordinary mod and has to be enabled in My Mods.

- If **SWBG-Data** is off in My Mods (for example after a crash or an update), enable it there. Or close DE and run Repair: press **R** in the exe, run `Repair-SWGB-DE.cmd`, or pass `-Repair`.
- Repair edits only `mod-status.json`, after backing it up. It enables SWBG-Data and the installer's Logic entry (the current copy of mod 549437, or the local SWBG-Logic if you are not subscribed or the subscription is a different version), points mod 549437's entry at its current folder, removes entries DE left behind for an older folder name and switches off any other Logic copy. It takes a second and regenerates nothing.
- When DE downloads a new version or a renamed listing of mod 549437, it renames the folder to `549437_<new title>` and rewrites its entry. Repair tidies up after that; the lobby keeps offering the mod either way.

## Play

1. Start DE. In **Mods > My Mods**, make sure **SWBG-Data** is enabled. SWBG-Logic shows as disabled there; that is expected (see above).
2. Go to **Single Player > Skirmish** and choose **SWBG-Logic** as the **Data Mod**. It resets to **Default** each time you open the lobby, so choose it every time. Its gear icon is expected.
   - If two SWBG-Logic entries appear, choose the local one (version 1.7): that is the one the installer set up. The other is your subscription to mod 549437, which is an older version (the installer switched it off).
   - If you are subscribed and the subscription matches this release, there is only one entry, mod 549437.
3. Choose **Galactic Empire** or **Rebel Alliance** and the map **SWGB Factions Savannah** (or another *SWGB Factions* map). For computer players, leave **AI** (the default). SWBG has one AI, the SWGB Classic AI. DE always lists its built-in **AI**, **AI (CD version)** and **AI (HD version)** (a mod cannot remove them), and SWBG-Data makes all three run the Classic AI, so every choice gives the same opponent at every difficulty. Use finite resources and Tech Level 1. Hard is the most tested difficulty.
4. Disable SWBG-Data for ordinary DE games. While enabled it replaces DE icons and all of DE's built-in AIs.

Updating from an earlier release: the installer, and Repair, delete the retired AI files (SWGB Land AI and the separate "SWGB Classic AI" entry) from your SWBG-Data, so they no longer appear in the lobby.

Online play needs the subscribed SWBG-Logic (mod 549437) at version 1.7, uploaded on October 22, 2026, to match this installer (1.6 and older use unit IDs that crash DE and do not match this SWBG-Data); a local SWBG-Logic is never offered in a multiplayer lobby. Every player also needs SWBG-Data from the same installer release. Online play with this release has not been tested, so treat it as experimental: it should work when every player has both, but that is not verified. The steps and known errors are in the Multiplayer section of README_GENERATED.md at https://github.com/stephenjayakar/SWBG-DE.

## Uninstall

Run the exe and press **U**, run it with `-Uninstall`, or double-click **Uninstall-SWGB-DE.cmd**. It removes SWBG-Data and the local SWBG-Logic, and also old SWGB-DE-Factions-* folders that an earlier installer version installed. It puts back any folders the installer had backed up and restores the previous `mod-status.json` state (entries it added are removed, enabled/disabled flags come back, migrated entries return with their folders). A subscription to mod 549437 is never removed; only its enabled flag is restored.

## What is in this download

- `SWGB-DE-Installer-<ver>-<build>.exe`: the launcher (`outputs/installer/exe/SwgbDeSetup.cs`, built by `outputs/toolkit/build_installer_exe.py` with the .NET Framework `csc.exe` that ships with Windows). It embeds the ZIP below unchanged. Its icon is the Galactic Empire civ emblem from SWBG-Logic.
- `Install-SWGB-DE.cmd`, `Repair-SWGB-DE.cmd`, `Uninstall-SWGB-DE.cmd`: run the installer, its repair mode, or uninstall.
- `installer\Install-SWGB-DE.ps1`: detection, checks, install, migration, repair, uninstall.
- `installer\SwgbDeBuilder.cs`: the converter. Windows PowerShell compiles it on the fly. It ports the project's SLP-to-SMX sprite pipeline, the WAV-to-Wwise-PCM sound conversion, the icon rendering and the atlas rebuild.
- `installer\recipe.tsv`: which SWGB/EF archive entry becomes which output file, with SHA-256 checksums. It contains no game data.
- `installer\tools\vgmstream`: the open-source vgmstream decoder (official r2117 Windows x64 release, see `COPYING`), used to decode the SWGB/EF OGG and MP3 music.
- `payload\`: the project's own files: `SWBG-Logic` (DAT, JSON tables, civ picker images; data-mod version 1.7, the game files for mod 549437 version 1.7) and the project-authored part of `SWBG-Data` (AI scripts, 20 random maps, the XS script and the English strings).
- `BUILD.json`: version, build commit, and the SHA-256 of every file.

## How releases are built

Releases are built by GitHub Actions (`.github/workflows/release.yml` in the repository) from a pushed `v*` tag, never by hand. The workflow runs `outputs/toolkit/package_installer.py` on `windows-latest`: it packages `payload/` and `outputs/installer/` from the repository, downloads vgmstream r2117 (`vgmstream-win64.zip`, SHA-256 `6c4a8a3813864fefed081bbd337dbc0ad93bf88e0b92f5db98d7ab258b22dc6c`), compiles the launcher with the runner's .NET Framework `csc.exe`, self-tests `-ExtractTo`, checks the `.sha256` files and attaches the exe, ZIP and checksums to a **draft** release. Releases stay drafts until the maintainer publishes them. The same command works locally: `python outputs/toolkit/package_installer.py [--label <name>] [--out <folder>]`.

## Known differences from the old full ZIP

- The 12 DE interface atlases are rebuilt from **your** DE version. Their SWGB icons are pixel-identical to the reference install. DE's own artwork on those sheets is taken from your current game, because DE has re-arranged the atlases since this build was made. All atlases are BC3-encoded; the reference panels atlas used BC7.
- 643 unused per-icon textures from an earlier design (`widgetui\textures\swgb`) are no longer installed. Nothing references them.
- All other generated files (sprites, sounds, music, icon textures) are byte-identical to the reference build when your SWGB + EF 1.5.5 files match the reference install. If your EF version differs, the files are still converted and the installer reports how many differ.
