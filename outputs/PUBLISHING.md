# Data-mod publishing

There is one data mod, **SWBG-Logic**. The same game files are published on ageofempires.com as unlisted [mod 549437](https://www.ageofempires.com/mods/details/549437/) and shipped by the installer as a local `SWBG-Logic` copy (`payload/SWBG-Logic` in the repository). The installer enables the subscribed copy when the player has one and otherwise installs the local copy (single player only, since DE lobbies only offer published data mods online). The media mod, **SWBG-Data**, is never published: the installer builds it from each player's own SWGB files.

The listing title is **SWBG-Logic** (formerly **SWGB-DE-Factions-Publish**; renamed on October 20, 2026 with a new description and no new upload; version 1.7 followed on October 22, 2026, still Unlisted). DE names the subscribed folder `549437_<title>`, so existing subscribers may still have `mods\subscribed\549437_SWGB-DE-Factions-Publish` until DE re-downloads the mod. The installer finds the subscription by its ID (the `549437_` folder prefix, or the WorkshopID in `mod-status.json`), never by its title, so either folder name works.

## Sharing and installing

Players subscribe to mod 549437 and run the installer from the GitHub release, which builds SWBG-Data and enables the subscription (see the README's Multiplayer section). Select the subscribed mod in the online lobby's Data Mod field and use the SWGB Factions maps. Publishing a new data version does not update anyone's SWBG-Data; when data and media change together, every player needs the matching installer release as well.

## Repeatable update workflow

1. Build, run offline checks, package and install on the development machine. Do not launch the game automatically.
2. Refresh the repository copy of the data mod: `python outputs/toolkit/package_installer.py --update-payload` (copies the shipped files from the development install after checking them against `recipe.tsv`). Commit, then let CI build the installer draft (see RELEASES.md).
3. Build the upload archive from the same files with `share_factions.py --build <commit>` / `package_faction_upload.py --build <commit>`. Its 16 game files must be byte-identical to `payload/SWBG-Logic`. Do not modify subscribed files or fabricate workshop registration.
4. Sign in via the owning Steam account (Firefox: Sign In, then Steam, then the Steam OpenID Sign In button) and open the [existing listing](https://www.ageofempires.com/mods/details/549437/), then edit it. Upload only the `-upload-data.zip`, preserving visibility and tags. Update description/change list to identify the build and runtime limitations. The description editor does not respond to Ctrl+A; triple-click the paragraph, delete, confirm it is empty, then paste.
5. Record publication only after the site confirms success. Preserve release history in CHANGELOG and RELEASES.md; remove older archives only after the new archives pass verification.

The upload archive has `resources/` and `widgetui/` directly at its root and contains 16 game files. The installer ZIP and the full share ZIP have wrapper folders, Markdown and build metadata and are unsuitable for website upload. Do not remove required DAT/JSON content merely to silence a validator. The 6260af2 archive (ten game files plus six civ-picker PNGs under `resources/_common/wpfg`) was accepted for version 1.6.

Versions 1.5 and 1.6 were uploaded directly through the website; no local publishing folder was used. The old local publishing folder name, `SWGB-DE-Factions-Publish` in `mods\local`, is migrated to a backup by the installer like the other old names. `update_faction_publish_copy.py` still exists for publishing through the game's My Mods UI. Always update the existing listing rather than creating another one.
