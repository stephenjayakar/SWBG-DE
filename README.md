This project ports two factions from Star Wars Galactic Battlegrounds (SWBG) into Age of Empires II Definitive Edition as a mod.

To use it, you have to:
1. Have SWBG installed
2. Have Expanding Fronts, a mod for SWBG, installed
3. Have AOE II DE installed
4. Run the setup.exe in the releases tab
5. Enable the 2 mods in the Age of Empires II DE menu under mods

We can't just post this mod to Steam Workshop, as it has copyrighted Star Wars assets from a game you have to buy. If someone finds out a better approach for releasing this mod, let me know! Please open issues if you see them, or if you have a better idea on how to release.

### Playing in Skirmish
Play as the Galactic Empire or Rebel Alliance in Skirmishes! When setting up a Skirmish, in the top right, click Data Mod and set it to this mod. You can leave the AI on the default "AI" - it runs the SWGB Classic AI. Difficulty Hard seems to be the best tuned. I tried to port the AI behaviors from the base game.

### Multiplayer
Multiplayer works. It's a bit difficult to setup though - you both have to have this mod installed. Then, you both have to subscribe to this [game logic mod](https://www.ageofempires.com/mods/details/549437/). When creating a multiplayer lobby, you'll have to select this data mod.
